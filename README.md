# UnboundInfotech Polymarket Alerts (Android)

Android app that scans public market data for opportunities, with one tab per type: cross-venue arbs, picks, bundles, crypto spot/funding, sports (needs an Odds API key), retail and tickets calculators. Uses real public data only and shows fees and risk honestly.

**Download:** see the [Releases](../../releases) page and install the `.apk` on your phone (allow installs from unknown sources).

This repo hosts release binaries only. It contains no source code.
